Deep Dive · How people actually code now

Stop prompting. Start looping. 🔁

🦞 Workflow
🦞
Peter Steinberger ✔ @steipete · PSPDFKit founder · agentic-coding evangelist
𝕏

Here's your monthly reminder that you shouldn't be prompting coding agents anymore. You should be designing loops that prompt your agents.

Jun 8, 2026 · 6.5M views

Prompting (old)

You type → it answers → you read → you type again. You're holding the wheel the whole time.

Looping (new)

You design the loop once. It finds work, does it, checks itself and repeats — while you sleep.

1Prompt
2Act
3Check
4Done?
Run #1 · start at Prompt

Each click = one step. If the check fails, it loops back. When tests go green, the loop exits.

claude-code
/loop babysit all my PRs. Auto-fix build issues, and when comments come in, use a worktree agent to fix them.

In Claude Code, /loop runs a prompt on repeat — or, with no interval, self-paces until the job is done.

⚠ A loop with nothing to push back is just the agent agreeing with itself on repeat. Same guy, 6 months earlier: “Just talk to it.” The tools finally got good enough to loop.

E — Execution Loop

The observe → think → act cycle, with error recovery. (Yes: this is the /loop idea, formalized.)

Which tools exist and how the agent picks the right one for the job.

C — Context Manager

What information actually makes it into the model's context window.

Memory that survives across turns and sessions.

🏆 The winning agent's playbook — click a pillar

Defense in depth — never one guard. Inputs get sanitised, validated and re-checked at every hop, so a single bypass isn't game over.

Independent sub-agents run side by side and cross-check each other — faster, and far harder for one poisoned branch to steer the whole.

Least privilege for tools: a tight, allow-listed surface means an injected instruction simply has nothing dangerous left to call.
